Privacy: this page shows aggregate stats, per-share metadata, and a persistent Share History (codes, filenames, sizes, download counts, creator IP, receiver pickup IP + time, and per-download receiver audit) — all behind the operator key. AnyDevice stores no user accounts or device info; IPs are captured once per share (creator at creation, receiver at first pickup, and at each download) for operator monitoring only. Share History retains metadata only — files and contents are deleted on expiry or burn, so a historical entry can never be downloaded again. The dashboard is a public static shell, but every data request requires the X-Admin-Key header.
